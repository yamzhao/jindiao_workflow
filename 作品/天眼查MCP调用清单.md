# 天眼查 MCP 调用清单

> 队伍：小盾未来队 | 题目：基础题-企业信用与风控尽调智能体

## 调用统计汇总

| 数据类别 | 工具名称 | 调用节点或方式 | 用途 |
|----------|----------|----------------|------|
| 企业类 | `search_companies` | 企业主体搜索 | 企业名称消歧、候选主体确认和企业 ID 获取 |
| 企业类 | `get_company_basic_profile` | 企业基础画像 | 工商登记、企业简介、标签和基础画像获取 |
| 企业与关联类 | `get_group_info` | 集团股权穿透 | 集团归属、控制关系和关联结构分析 |
| 企业与关联类 | `get_equity_ratio` | 股权控制结构查询 | 股权控制结构及疑似实际控制人路径分析 |
| 董监高类 | `get_company_people` | 企业人员画像 | 法定代表人和主要人员信息获取 |
| 董监高类 | `get_person_risk_profile` | 企业法人风险画像、循环获取人员风险 | 法定代表人和主要人员个人风险核验 |
| 经营类 | `search_bids` | 经营与处置线索 | 招投标、资产处置及经营活动线索获取 |
| 知识产权类 | `search_patents` | 专利检索 | 专利和技术活动线索获取 |
| 风险类 | `get_risk_overview` | 获取可用工具后经 `call_tool` 循环调用 | 风险总览查询 |
| 风险类 | `get_judicial_case` | 获取可用工具后经 `call_tool` 循环调用 | 司法案件查询 |
| 风险类 | `get_judgment_debtor_info` | 获取可用工具后经 `call_tool` 循环调用 | 被执行人信息查询 |
| 风险类 | `get_dishonest_info` | 获取可用工具后经 `call_tool` 循环调用 | 失信被执行人信息查询 |
| 风险类 | `get_high_consumption_restriction` | 获取可用工具后经 `call_tool` 循环调用 | 限制高消费信息查询 |
| 风险类 | `get_administrative_penalty` | 获取可用工具后经 `call_tool` 循环调用 | 行政处罚信息查询 |
| 风险类 | `get_serious_violation` | 获取可用工具后经 `call_tool` 循环调用 | 严重违法失信信息查询 |
| 风险类 | `get_equity_freeze` | 获取可用工具后经 `call_tool` 循环调用 | 股权冻结信息查询 |

**合计**：覆盖 6 个类别、16 个不同工具。其中风险专项链路通过“获取可用工具 → 提取工具 → 循环获取企业风险 → 获取工具参数 → `call_tool`”完成多维度风险信息采集。

- [x] 不少于 2 个类别：实际覆盖企业、企业与关联、董监高、经营、知识产权、风险 6 个类别
- [x] 不少于 3 个不同工具：实际覆盖 16 个不同工具
- [x] 覆盖企业基本信息、股权及控制关系、人员风险、经营线索、知识产权和风险专项信息
- [x] 提供调用清单；运行日志可作为各节点输入、输出和调用过程的佐证材料
