# 基础题 - 部署与使用文档

## 一、环境要求

- 华为云 AgentArts 平台账号及工作流编排、运行权限。
- 天眼查 MCP 服务访问凭据。
- 网络可访问天眼查 MCP 服务端点：`https://mcp.tianyancha.com/mcp`。
- 推荐使用 Chrome、Edge 等现代浏览器访问 AgentArts 控制台。

## 二、部署步骤

1. 登录华为云 AgentArts，进入 MCP 工具管理页面，创建天眼查 MCP 工具并完成连接配置：
   - 服务端点：`https://mcp.tianyancha.com/mcp`
   - 鉴权方式：按照竞赛环境配置天眼查 MCP 访问凭据
   - 凭据管理：凭据仅在 AgentArts 连接配置中保存，不写入工作流文件和提交文档
2. 创建完成后，使用平台的 MCP 调试功能调用任一工具，确认服务端点、鉴权和工具返回均正常。
3. 在浏览器页面按 F2，查看并记录新创建 MCP 工具的 ID。例如：`725ef8e3c9b24f1a8e7d3c5b9f2a4e6d`。
4. 使用文本编辑器打开 `workflow_企业信用尽调智能体_1_20260905171413.jsonl`，将文件内所有 MCP ID `521eba63de854dd98bafc65c9baf4e2f` 替换为步骤 3 中记录的新 MCP 工具 ID，并保存文件。
5. 返回 AgentArts 工作流或智能体编排页面，导入已替换 MCP ID 的工作流配置文件。
6. 检查工作流中的 MCP 节点是否正常加载，包括企业主体搜索、企业基础画像、集团股权穿透、股权控制结构查询、企业人员画像、人员风险、经营与处置线索及专利检索节点。
7. 保存工作流并运行测试，确认 MCP 节点、人员风险循环、风险专项 `call_tool` 循环、风险评分和报告节点均能正常执行。

## 三、使用说明

1. 在 AgentArts 对话框输入企业名称，例如“华为技术有限公司”，或输入企业名单（每行一个企业名称）。
2. 智能体自动执行数据获取、交叉分析、风险研判和报告生成：先确认企业主体并获取基础工商信息，再穿透集团股权和主要人员风险，查询经营、专利及司法、失信、限高、行政处罚、股权冻结等风险信息。
3. 系统输出 Markdown 格式的企业信用尽调报告。报告包括企业基本信息、股权结构及控制关系、分级风险清单、风险评分、结论与建议；可根据实际业务需要将 Markdown 报告转换为 Word 格式存档。
4. 在 AgentArts 运行详情中保存 MCP 节点输入、输出和运行日志，并与天眼查 MCP 调用清单一并作为提交佐证材料。

## 四、常见问题

| 问题 | 解决方案 |
|------|----------|
| MCP 调用超时或连接失败 | 检查网络连通性、服务端点和访问凭据；确认天眼查 MCP 服务状态正常后重试 |
| 工作流导入后 MCP 工具不可用 | 新创建的 MCP 工具 ID 可能未正确写入工作流文件。确认 MCP 工具存在后，将 `workflow_企业信用尽调智能体_1_20260905171413.jsonl` 中的原 MCP ID 全部替换为新 MCP 工具 ID，再重新导入 |
| 未查询到企业信息 | 企业名称输入错误或不存在时，系统会返回“未查询到企业，请确认输入是否正确”。请核对企业全称或统一社会信用代码后重新输入 |
| 风险专项工具未返回数据 | 检查 `get_company_capabilities` 返回的工具权限和参数要求；空结果仅表示当前查询未返回记录，不等同于无风险 |
| 人员风险循环耗时较长 | 主要人员数量会影响循环次数；可在工作流运行详情中查看单个人员节点状态 |
| 报告生成不完整 | 检查企业基础画像、集团股权穿透、人员风险、风险专项调用和风险评分节点是否均有输出；必要时根据日志定位异常节点 |
